# Lab Write-ups

Organize solutions by vulnerability topic. Create one Markdown file per lab, using a descriptive filename.

Suggested topic folders: access-control, authentication, business-logic, command-injection, csrf, file-upload, path-traversal, ssrf, sql-injection, xss, and other topics as needed.

Use the write-up format in the repository root README. Remove or redact session cookies, lab tokens, and other secrets before committing.
